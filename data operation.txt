Steps of Project :

In this project, I started by downloading the course dataset from Kaggle and uploading it into Power BI's Power Query Editor. I began the data preparation by checking data quality—removing errors, duplicate records, and blank rows across all columns. I retained the `id` column but renamed it to `Course_Id`. Irrelevant and empty columns that were not aligned with the problem statement were also removed. Specifically, the `Category` column was cleaned by eliminating null or blank values, and the `URL` column was dropped entirely. In the `Rating` column, I removed the "star" text using the “Extract Text Before Delimiter” transformation and converted the resulting values from text to decimal number format. Once the data was cleaned, I loaded it into Power BI Desktop for analysis.

The client's first priority was category-wise insights, so I created a bar chart showing the count of courses (`Course_Id`) per category. Next, I calculated the average number of viewers per category, sub-category, and language to analyze engagement patterns. To highlight trending skills, I visualized the `Skills` column using a word cloud, removing common stopwords for clarity. A pie chart was created to display the number of courses offered in each language. To identify the most popular course categories, I developed a ranking measure using DAX to display the top five categories based on average viewer count. This was visualized alongside language data to understand regional preferences.

Further analysis focused on subtitle availability. I cleaned the `Subtitle Language` column by removing irrelevant text and blank values, then created a custom column that counted the number of subtitle languages using a text split and count logic. This was followed by a line chart showing the relationship between subtitle count and average viewer numbers, revealing that more subtitle options tend to attract more viewers.

To analyze instructor performance, I created a duplicate table called `Teachers` to prevent data loss. This table included only key fields: `Course_Id`, `Category`, `Sub-Category`, `Instructor`, and `Rating`. The `Instructor` column was cleaned by removing trailing commas, splitting entries by commas, and unpivoting the resulting columns. After cleaning unwanted titles or degrees from instructor names, I created a DAX measure to rank instructors based on average ratings and displayed the top 3 using a table visual with a sub-category slicer.

Duration data was standardized by creating a custom column that converted months to hours (multiplied by 60), extracted hours directly, and converted minutes to fractions of an hour. If none of the keywords matched, a default duration of 200 hours was assigned. The original `Duration` column was removed, the new column was renamed to `Duration_in_hours`, and converted to a whole number. A line chart was then used to show the trend between course duration and viewer count, demonstrating that longer courses typically attract more viewers.

Finally, to analyze skill density, I created a custom column in Power Query to count the number of skills provided by calculating the number of commas in the `Skills` column. This value was then converted to a whole number to support quantitative analysis in later visuals.

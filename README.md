# EdTech_Dashboard
🚀 Power BI Project: EdTech Course Data Analysis Using Kaggle Dataset

I recently completed an end-to-end Power BI dashboard project focused on analyzing EdTech course data to support strategic decisions for recorded lecture expansion. The project leveraged a Kaggle dataset and placed strong emphasis on category-wise insights to uncover trends in course content, viewer behavior, and skill demand.

🔍 Key Highlights:

Cleaned and transformed raw data in Power Query Editor: handled nulls, duplicates, and standardized fields like ratings, duration, and subtitles.
 Built category-focused KPIs  to reveal course distribution, content gaps, and learner engagement.
 Created impactful visuals—bar charts, pie charts, line charts, and word clouds—to explore:

  Top-performing course categories and instructors
   Viewer engagement vs. course duration and subtitle availability
  Skill demand trends and instructor performance using DAX-based custom rankings
  Language distribution and its impact on accessibility
 Developed logic to assess subtitle influence, skill variety, and course language on viewership.
 Applied data modeling and relationships to ensure analytical accuracy.

📈 Business Impact & Recommendations:

* Prioritize high-viewership categories like Data Science, IT, and Computer Science for new content.
* Increase multilingual offerings and subtitle support to boost reach.
* Focus on in-demand skills such as Python, Machine Learning, and Data Analysis.
* Use duration insights (optimal: 50–60 hrs) to guide course structuring.
* Highlight top-rated instructors and align new content with trending subcategories.

💡 Key Tools: Power BI, Power Query, DAX, Data Modeling, Visual Analytics

This project strengthened my ability to transform raw datasets into business-ready dashboards and draw strategic insights that drive growth.
